# Dark-Null-Protocol

Groth16 privacy settlement on Solana. ZK proofs. AES-256-GCM.

Agents prove payment history without revealing wallet, amounts, or counterparties. Groth16 + alt_bn128 Solana syscalls. Ceremony required before mainnet.
